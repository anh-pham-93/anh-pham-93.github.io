# anh-site

Anh Pham's personal website. Built with Astro, published automatically to GitHub Pages on every push to `main`.

- Live: https://anh-pham-93.github.io
- Content is Markdown files in `src/content/` (from Phase 3 onward)
- Design rules live in `DESIGN.md`; working conventions in `CLAUDE.md`

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Local preview at http://localhost:4321 |
| `npm run build` | Build the production site into `dist/` |
